# 研究计划（deep-research Phase 1–3）

## 1. 问题重构
原始需求：仿照参考论文（唐欣琳，2026，《管理科学与工程》15(3):721-731，文献综述+理论分析型）写一篇 GEO 广告方向论文，投知网收录期刊；参考文献必须真实可查，行文不做防御性写作。

重构后的研究问题：
生成式引擎优化（GEO）正在从“内容可见性技术”演变为一种新的广告投放形态。这种广告化过程的运作机制是什么？它给广告可识别性、信息质量和市场竞争带来哪些具体风险？广告主、平台、GEO 服务商和监管者应如何应对？

参考论文只把 GEO 当作出版商的应对策略之一（5.4.1 节），本文把 GEO 本身作为研究对象，补上其“广告属性”与治理这一空白。

## 2. 可证伪假设
H1：GEO 的投放对象从“用户注意力”转向“模型的检索与引用偏好”，其效果依赖检索排序与内容结构，而非创意。
H2：GEO 与平台付费广告并行，形成“付费嵌入广告 + 未标注的优化内容”双轨结构；后者在现行广告法框架下处于可识别性灰区。
H3：GEO 的可操纵性（策略性文本、对抗性注入、检索投毒）会把搜索广告时代的 SEO 作弊问题放大为信息安全问题。
H4：零点击化使 CPC/CPM 计价与效果评估失灵，需要以“被引用/被推荐”为单位的新度量。

## 3. 框架（litreview：Decomposition）
| 组件 | 映射 | 子领域 |
|---|---|---|
| Problem | AI 搜索改变流量与广告逻辑 | D. 搜索经济学与零点击 |
| Solution/机制 | GEO 方法与生成式广告机制 | A. GEO 机制；B. LLM 广告拍卖/嵌入 |
| Evaluation | 用户识别、效果、操纵风险 | C. 原生广告披露；F. 操纵与攻击 |
| Limitations/制度 | 中国监管与市场 | E. 法规与市场数据 |

## 4. 来源策略
- 环境限制：学术 API（OpenAlex/Crossref/arXiv/doi.org）被网络策略拒绝，WebFetch 无法解析域名；仅 WebSearch 可用。
- 核验规则：每条文献至少通过一次精确标题检索命中出版方/预印本/机构页面，记录作者、年份、出处、卷期页或 arXiv 号；不能核实的条目不进入参考文献。
- 来源类型：同行评议论文（主）、顶会论文/预印本、法规原文、权威调查机构（Pew、CNNIC）、行业公告。
- 反向检索：GEO 无效/被高估、AI 搜索未减少点击、原生广告披露无效等反方证据。

## 5. 风险登记
- 风险：预印本数据被当作定论 → 正文写明“实验”“基准”范围。
- 风险：行业数据口径不一 → 只用一手发布方数据并写明时间与口径。
- 风险：中文文献无法从知网直接核验 → 只用能在出版方/期刊官网/权威转载处核实的条目。

## 6. 停止条件
每个子领域 ≥4 条核实来源；总参考文献 30–40 条；每条正文论断可回溯到 sources/ 中的记录。
